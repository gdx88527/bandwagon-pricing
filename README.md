**搬瓦工是个什么底子**

**CN2 GIA 到底贵在哪**

搬瓦工官网对这事的解释挺实在，值得直接引用它的逻辑。中国方向的 IP 传输有四条路：最普通的 ChinaNet 163 骨干网，便宜但晚高峰拥塞，丢包率可以到 30% 以上；CN2 GT，本意是保证服务质量，但 2019 年之后拥塞程度跟 163 差不多了；CN2 GIA，中国电信最贵的一条通道，每兆比特的传输成本最高能到 120 美元，1Gbps 带宽一个月的账单在某些市场能达到约 10 万美元，换来的是最稳定的路由质量；最新的 CTGNet，官方认为实际表现跟 CN2 GIA 基本等价。

搬瓦工在洛杉矶部署了跨两个机房的 8 条 10Gbe CN2 GIA/CTGNet 链路。其中 USCA_9（就是套餐表里的 DC9）把所有去往中国的流量分给三个运营商：电信 CN2 GIA、移动 CMIN2、联通精品网 AS10099，同时和 Google 等本地网络直连。这就是为什么香港、东京的 CN2 GIA 套餐贵，而洛杉矶的 CN2 GIA-E 便宜——同样的线路质量，洛杉矶的带宽采购成本低得多。如果延迟不是极端敏感，官方自己的建议也是优先考虑洛杉矶。

**机房和免费迁移：买错了一般也能救**

搬瓦工的多机房套餐支持在 KiwiVM 面板里一键迁移，数据自动搬过去，几分钟完成，不额外收费。CN2 GIA-E 和迪拜系列可迁的机房最多，覆盖洛杉矶 DC6/DC9、日本 JPOS_1、荷兰 EUNL_9 以及常规的 DC3、DC8 等。

两个细节要留意：迁移过程消耗的流量会计入当月总额；另外热门机房（尤其 DC6、DC9）容量有限，迁移时可能提示已满，需要等放位。所以"先买便宜的机房、之后再迁去 CN2 GIA 机房"这条路是通的，但能不能立刻迁过去要看运气。

关于 CPU 用量，搬瓦工的政策是：允许短时间跑满 CPU，但一个小时内平均用量不能超过套餐上限，超了之后系统会自动限频，不会直接停机。跑持续高负载任务的话，这个规则比"峰值不限"重要得多。

操作系统方面，官方支持 AlmaLinux、Rocky Linux、CentOS、Debian、Ubuntu、Fedora 等主流发行版，也支持手动挂载 ISO 安装，但没有 Windows 镜像。备份和快照是所有套餐免费自带的，KiwiVM 每隔几天自动做一次全量备份，随时可以还原。

退款方面，官网明确提供 30 天退款保证，迪拜产品页的原话是"行业内最宽松之一"。第三方教程总结的退款条件是：账户注册 30 天内、之前没退过款、IP 未被封，基本都能全额退。超过 30 天就没有退款这回事了，这一点下单前想清楚。

**几个常见问题**

网站放搬瓦工需要备案吗？不需要。服务器在海外（洛杉矶、香港、东京等），域名解析过去就能直接访问，不经过国内备案流程。但香港机房虽然物理上近，备案问题同样不存在，这一点不用纠结。

流量用超了怎么办？超出部分套餐不会自动断网，但按搬瓦工的计费规则会产生费用或需要购买叠加流量，跑大流量业务前先算好月用量，别选刚好卡线的档位。

IP 被封了怎么办？SLA 系列每两周可以免费换一次；其他套餐可以在 KiwiVM 面板申请更换，通常需要支付小额费用。买之前把"换 IP 成本"也算进使用成本里，这是很多人会漏掉的项。

买错了能退吗？30 天内、满足上面说的条件，可以全额退。用 PayPal 或信用卡付的，退款原路返回，一般几个工作日到账。
